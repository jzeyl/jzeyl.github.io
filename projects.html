Skin Model Maker

A 3D Slicer plugin for designing a 3D printable skin model for surgical planning from abdominal scan. The user imports a CT scan and csv file containing a series of x-y coordinates representing target surgical endpoints. The software returns a 3D model representing the outer skin surface with holes corresponding to the user csv file. The csv data and GUI interface allows for adjustments of hole size and position of embossed labels.
