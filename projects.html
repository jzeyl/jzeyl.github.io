Retainer Designer

A plugin for designing an orthodontic retainer wire for to give instructions for wire-bending machine. The user sets a 3D plane to intersect through through a jaw model and generate points representing the retainer wire. Points can be adjusted in a 3D view with real-time visual feedback of constraint parameters.

Skin Model Maker

Plugin to design a 3D printable skin model from abdominal scan with entry holes and labels for surgical planning. The user imports a CT scan and csv file containing a series of x-y coordinates representing target surgical endpoints. The software returns a 3D model representing the outer skin surface with holes corresponding to the user csv file. The csv data and GUI interface allows for adjustments of hole size and position of embossed labels.
